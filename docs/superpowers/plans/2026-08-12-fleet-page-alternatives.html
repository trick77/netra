netra · fleet page study

Who Needs Me First

The fleet page currently opens with three numbers nobody acts on, then a table of four sparkline columns that answer what changed — while the question you came with is who needs me. Same data, three answers. Each mock is shown at four hosts and then at sixty, because scale is where the current design actually breaks.

A

Exceptions, then everything else

The page states the fleet's condition in one sentence, gives every unhealthy host a full row with the reason in words, and compresses the healthy majority into a quiet table below a fold line. The three stat tiles are gone: "22 containers" is not a thing anyone does something about.

Fixes
Answers the question you arrived with, in the first line, in words. Scales: the exception band stays the same size whether the fleet is 4 or 400.
Costs

Best if

B

The wall

One tile per host, sorted worst-first, colour carrying the worst thing true about that machine. Sixty hosts fit above the fold; four look deliberately sparse rather than broken. Each tile says the one fact that matters and two numbers — no sparkline, because at this size a sparkline is texture, not information.

C

The working table

Keeps the table you have — it is genuinely good — and fixes what it is missing: a Worst column stating the single most serious fact per host in words, severity sorting by default, grouping by site, and rows tinted rather than badged. The four sparkline columns collapse to two, because CPU and memory are the ones people read.

True of all three

  • The three stat tiles go. "Hosts reporting 4 of 4", "Containers 22", "Fleet traffic 225.4 Mb/s" occupy the most valuable strip on the page and nobody has ever acted on any of them. The first is one sentence; the other two are trivia.
  • Severity has to be sortable and default. Right now the list is name-ordered and the badge only appears on the exception — so finding it means reading every row. The thing you came for should be at the top without you asking.
  • Every host needs one sentence, not five charts. Sparklines say what changed; none of them says what is wrong. "3 OOM kills" is the sentence, and it exists in the data already.
  • Site grouping is free. site_name is already on the row and is used only as grey subtitle text.
